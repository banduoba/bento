# Bento 路线图

计划来源：[Bento 产品计划](https://bento-b6tq.pages.grok.bot/)，网页状态截至 2026-10-31。原则：稳、快、原生、离线；按功能分支和 PR 推进，Bai 验收后再合入 main。下表区分代码已有状态与验收状态，不沿用来源网页的旧勾选。

## 当前交付与近期优先级

| 项目 | 当前状态 | 后续 |
|---|---|---|
| 搜索：当前列表过滤、递归搜索、结果定位、格式过滤、取消 | feat/search-reliability-native 已实现，待代码审查、原生 QA 和 Bai 验收；尚未合入 main | 完成验收后交付 |
| M4：窗格/标签历史与会话恢复 | 已合入 main（#18） | — |
| 原生文件操作与整批基础 Undo | 已合入 main（#23） | — |
| 日期、序号、大小写及基础预览 | 已实现；完整人工/真机验收未确认 | 后续按反馈完善 |
| 正则捕获替换 | 尚未实现 | 单独后续功能 |
| 深色模式 | 已实现；验收状态未确认 | 后续核对视觉与系统外观跟随 |
| 文件夹大小后台计算、缓存和排序 | 用户暂缓 | 暂不排期 |

## 后续候选

| 阶段 | 计划项 | 当前边界 |
|---|---|---|
| Phase 2B | 标签/工作区；可展开文件夹树侧栏 | 标签/工作区已实现；侧栏是独立于现有行内展开的功能，尚未标记实现 |
| Phase 2C | Drop Stack；压缩包按文件夹浏览及解压进度；Finder 接管/对话框导航 | 依反馈选择；Finder 相关先做技术调研 |
| Phase 3 | 性能、刷新、图标、键盘、信任与验收 | 仅有阶段概览，不据此补写未读到的细项 |
| Phase 4 | 尚未排期 | Phase 1–2 稳定后再考虑；AI 搜索、完整 Finder 替代、远程协议和同步当前不在范围内 |

可选项是否推进按反馈确定；网页未明确的状态不作推断。
