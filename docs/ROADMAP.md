本地开发计划与调研：[Bento 优化与功能开发计划（含调研来源）](Bento-%E8%AE%A1%E5%88%92%E4%B8%8E%E8%B0%83%E7%A0%94.md)。该文档是后续开发的主要计划来源，保留原始调研、链接和用户提供的规划内容；本文仅作状态索引。历史网页计划截至 2026-10-31：[Bento 产品计划](https://bento-b6tq.pages.grok.bot/)。

## v0.3.0 发布候选

本候选版本纳入 PR #27 的侧栏文件夹树、工作区下方的当前窗格标签和行内重命名改进，并包含当前 main 已有的 pane/tab 历史与会话恢复、About/检查更新、原生文件操作与基础 Undo、搜索和正则捕获替换。侧栏宽度默认 220px（180–520px，可双击重置），名称列默认 260px；列视图设置为全局默认并允许按文件夹覆盖。常规文件操作委托 macOS Finder，重名和冲突行为由系统处理。About 检查后打开下载页面，不会自动安装。
