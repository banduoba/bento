# Bento 需求调研（2026-10-30）

来源：Reddit r/macapps、MacRumors、知乎、掘金、HN、App Store 评论中关于 QSpace / Path Finder / Commander One / Finder 的讨论。

## 同类软件被吐槽的点

| 吐槽 | 来源 | Bento 现状 |
|---|---|---|
| 功能过多显得笨重、启动慢（弃用主因） | Reddit「Why I Am Ditching Third-Party File Managers」 | ✅ 定位即轻量：Tauri + Rust，启动毫秒级，坚持克制加功能 |
| 「功能过 blowing up 到难以上手」（QSpace） | MacRumors | ✅ 交互对齐 Finder，功能不堆砌 |
| 地址栏编辑不直观 | 知乎评测 | ✅ ⌘L 可交互地址栏 + 面包屑折叠 |
| 批量重命名规则弱（加日期、改大小写费劲） | 掘金对比 Path Finder | ⚠️ 日期、序号、大小写和基础预览已有实现；正则捕获替换仍待后续实现，细节见 [路线图](ROADMAP.md) |
| 服务器连接只读、NAS 不稳定 | 知乎 / GitHub | ❌ 暂不做（保持轻量），远程协议是 Pro 级功能 |
| 双栏/多视图布局受限 | 掘金 | ✅ 10 种布局预设 |
| 无文件夹内容可视化预览 | Facebook 讨论 | ✅ 树形展开 + 快速查看（Space） |
| 缺少快捷键管理选择（如一键取消全选） | App Store 评论 | ✅ Esc 取消；⌘Z 撤销移动 |

## 用户高频诉求方向（社区共识）

1. **快与轻** —— 启动、扫描、搜索响应速度是第一需求（fsearch 引擎已覆盖）
2. **批量操作能力** —— 重命名规则增强（日期戳、计数、大小写、正则替换）
3. **多视图** —— 树形、分栏、预览面板
4. **键盘优先操作** —— 快捷键完备（⌘L/⌘K/⌘,/⌘Z/Space 已覆盖核心）
5. **外观跟随系统** —— 深色模式已有实现；人工验收状态见[路线图](ROADMAP.md)
